# Sistema de Control de Rescate y Adopción Animal

## Descripción del proyecto

El Sistema de Control de Rescate y Adopción Animal es una propuesta de software orientada a facilitar la gestión de animales rescatados en un refugio.

La plataforma permitirá registrar casos de rescate, clasificar animales por especie, asignar voluntarios y veterinarios, controlar tratamientos y gestionar procesos de adopción.

## Objetivo general

Diseñar una arquitectura lógica para un sistema de gestión de rescate y adopción animal, aplicando diagramas UML, patrones de diseño y buenas prácticas de control de versiones mediante Gitflow.

## Actores principales

- Ciudadano o reportante.
- Voluntario.
- Veterinario.
- Administrador del refugio.

## Funcionalidades principales

- Registro de casos de rescate.
- Clasificación de animales por especie.
- Asignación de responsables.
- Seguimiento del estado de los animales.
- Registro de tratamientos veterinarios.
- Notificaciones automáticas.
- Gestión de adopciones.

## Patrones de diseño

- Singleton.
- Observer.
- Factory Method.
- MVC (Model-View-Controller).

## Metodología de trabajo

Se utilizará Gitflow para organizar el desarrollo mediante las ramas master, develop y feature.

## Herramientas utilizadas

- GitHub.
- Lucidchart.
- UML.
